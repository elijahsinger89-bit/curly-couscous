RELEASE PROBE v3 (read-only) - for the go-to-machine script

What it is for
  1. The arguments of the posting calls (JobListSet.CalculateNC, Run, RunAll,
     JobList.GenerateNCListFile, GetGenerateAndReleaseNcInfo ...).
     hyperMILL's API has no help text, so v3 asks each built-in method with a
     made-up argument name: hyperMILL refuses the call before running
     anything and lists the arguments it accepts. Methods that change the
     document (Set, Create, Delete, Remove, Reset ...) are not asked.
  2. Status and POFStatus of EVERY job (v2 stopped at 60 compound jobs) and
     the POF file name of each job.
  3. The text of the VNC\ files Simulation Center writes (.nclist,
     .settings), and the newest files in POF\ and NC\.

Install
  Copy copy_to_python_folder\release_probe into
  C:\Users\Public\Documents\OPEN MIND\python (replace v2) and restart
  hyperMILL.

Run
  Save your work. Open the same saved copy as before, right after a
  Simulation Center run (some compound jobs simulated, not all; note which).
  Run release_probe. The log is written line by line; if hyperMILL freezes,
  close it and send the log anyway.

Send back
  C:\Users\Public\Documents\OPEN MIND\release_probe_log.txt
  and which compound jobs you simulated.

What it changes
  Nothing. No NC file is written, nothing is calculated.
